Linked Lists: Insertion

Lesson Text

A linked list stores items in sequential memory nodes. Each node holds a value and a pointer reference to the next node in the structure.

To insert at the head, create a new node and point its pointer to the existing head node.

Finally, update the head reference pointer so the list starts directly from the newly created node.
